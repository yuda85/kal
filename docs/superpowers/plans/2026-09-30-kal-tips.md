# Tips Tab Implementation Plan

> Written while the owner was away; executed inline in the same session. Spec: §17.

**Goal:** Tips tab with 50 tips, stars, saved videos via confirm-link, and a blocking daily tip.

**Architecture:** Tip content and the daily-pick rules live in `domain/` (`tips-data.ts`, `tips.ts`). A new link op `video` goes through the usual codec → `planWrites` → repository. The app adds `meta/tips` and `videos` watchers to `KalState`, a `/tips` page and a `DailyTip` dialog in the shell.

## Tasks

1. **Domain tips** — `domain/tips-data.ts` (`TIP_TOPICS`, `TIPS`), `domain/tips.ts`:
   `tipReason(yesterday: DaySummary | null): TipReason | null`,
   `pickDailyTip(state: TipState, reason: TipReason | null): { tip: Tip; reason: TipReason | null }`,
   `closeDailyTip(state: TipState, pick, today): TipState`, `toggleStar(state, id): TipState`,
   `videoPlatform(url): string`. Tests in `domain/tips.test.ts` (reasons and their order, rotation, recent, 50 unique ids, every topic has tips).
2. **Link op `video`** — `domain/link.ts` (type, keys, validation, `fillDefaults` id), `domain/apply.ts` (`PlannedWrites.videos`), tests in `link.test.ts` / `apply.test.ts`; `confirm.logic.ts` describes it; skill `SKILL.md` section "Videos".
3. **App data** — repository `watchTipState`, `saveTipState`, `watchVideos`, `deleteVideo`, `applyWrites` writes videos; fake repository; `KalState.tipState` (`undefined` until loaded) and `videos`.
4. **Daily tip dialog** — `features/tips/daily-tip.ts` in the shell; check-in auto-open waits for it. Spec for show/close.
5. **Tips page** — `features/tips/tips.ts` + `tips.logic.ts` (sections by filter), route, fifth tab. Spec for the logic.
6. Verify (`npm test`, typecheck, `ng test`, `ng build`), commit, push to `main`.
